# Do You Have? Match

小学4年生の外国語活動「Do you have a ...?」で使う対面会話ゲームです。児童が見るのは自分の4枚だけ。相手の持ち物は実際に質問して確かめます。

Web版: https://ryonma-git.github.io/DoYouHave-Match/

## 授業の準備

1. タイトル **Do You Have?** を1.8秒以内に3回タップします。
2. 先生用パスコードを入力して管理画面を開きます。
3. 10種類の候補から、授業で使う4〜10種類を選びます（初期値は5種類）。
4. 欠席・対象外の番号のチェックを外します。出席者は2〜40人です。
5. 配布パターンを確認します。最初の先生用アクセスでは8パターンからランダムに選びます。「ランダムに選び直す」でも変更できます。
6. **授業URLをコピーして全員に同じURLを配ります。** URLに使用アイテム・出席者・配布パターンが含まれます。

設定を変えた場合は、新しいURLを全員に配り直してください。端末間の自動同期はありません。設定付きURLを使わずトップページから始めた場合は、初期5種類・1〜40番・パターン1です。

## 児童の操作

出席番号 **1〜40** を入力すると、その授業設定と番号で決まる4枚が配られます。

1. 4枚と位置を覚え、**I'm ready!** を押します。
2. **START** で計測開始。相手に英語で質問します。
3. 相手が持っているアイテムの位置を思い出して開きます。間違えて閉じ直すと **+5秒** です。
4. 同じ相手と3枚以上一致したら **MATCH!**。相手を変えるときは **NEXT PERSON** を押します。カードだけが閉じ、タイマーは続きます。

## 出席番号99の一覧表

先生用認証を済ませてタイトルに戻り、出席番号 **99** を入力すると、その設定での1〜40番の配布一覧・カードの位置・マッチできる相手を表示します。未認証の99入力や管理画面URLの直接入力では一覧は開けません。通常の先生用メニューには配布一覧を出しません。

## 配布と欠席への対応

出席番号の並びと8つの固定seedで配布を再現します。端末ごとに別々のパターンを選ぶと候補を保証できないため、先生が選んだパターンを授業URLで共有します。

- 出席者を混ぜ、基本5〜9人のグループに分けます。5人未満は全員で1グループです。
- 各グループに選択アイテムから5種類の小さな候補集合を作り、各児童には4種類を配ります。選択が4種類ならその4種類を使います。
- 同じグループのどの2人も3種類以上が共通します。2人以上の出席者がいれば全員に候補が存在します。
- 出席者5人以上なら全員に最低4人の候補があります。そのため、配布を変えずに後から任意の3人が欠席しても孤立しません。管理画面には今回の実際の最少候補人数と、その人数に応じた追加欠席への耐性を表示します。
- あらゆる欠席数への保証はできません。欠席が多い場合は出席者を更新して再配布してください。単独になった児童を自動検知する通信機能はありません。

表示する確率は2種類です。「無作為配布の目安」は2人がそれぞれ独立に4種類を選ぶ場合の理論値 `(1 + 4 × (N − 4)) / C(N,4)`。「今回マッチできる組」は、この配布で3種類以上共通する出席者ペアの割合を全ペアから計算した実測値です。目安は5種類で100%、6種類で60%、10種類で約11.9%。実際の配布では上記のグループで孤立を防ぎます。

## 先生用メニューの保護

- パスコード入力は、成功・失敗を合わせて同じ保存状態で5回までです。
- 間違えると入力画面が閉じます。5回未満なら再度タイトル3回タップで呼び出せます。5回に達すると呼び出せません。
- Cookie（1年間）とlocalStorageに回数を保存するため、通常の再読み込み・ハード再読み込みではリセットされません。
- 認証はそのタブで30分間有効です。「閉じてロック」または児童のゲーム開始で解除されます。Swift版はCookieの代わりに端末のUserDefaultsに回数を保存します。
- 静的サイトの児童向け誤操作防止です。開発者ツール、ソース解析、サイトデータ全消去、別ブラウザーまで防げるサーバー認証ではありません。

## 開発・起動

Web版はルートで `python3 -m http.server 8000 --directory docs` を実行し、`http://localhost:8000/` を開きます。静的ファイルだけで動作します。ゲームを読み込んだ後の操作にネット通信は不要です。オフライン再読み込みのキャッシュは実装していません。

Swift版は `swift/DoYouHaveMatch.xcodeproj` をXcodeで開き、iPadOS 16以上のiPadまたはシミュレータで実行します。実機では開発用署名が必要です。`cd swift && xcodegen generate` でプロジェクトを再生成できます。先生用メニューでWebと共通の授業URLを読み込み・共有できます。

`npm ci && npm test` でゲーム・配布・先生用アクセス・画面操作のテストを実行します。linkedomはテスト専用で、配信サイトに依存ライブラリはありません。

SwiftとWebのカード・配置の一致を確認するには：

```sh
node tests/export-swift-fixtures.js > /tmp/dyhm-swift-fixtures.json
swiftc swift/DoYouHaveMatch/Classroom.swift tests/SwiftParity.swift -o /tmp/dyhm-swift-parity
/tmp/dyhm-swift-parity /tmp/dyhm-swift-fixtures.json
```

`docs/`が静的Web版、`swift/`がSwiftUI版、`tests/`が検証コードです。GitHub Pagesは`main`ブランチの`/docs`から配信します。

iPad実機でのSafari表示・タッチ操作とSwiftUI全体のビルドは未確認です。SwiftUIビルドには、このMacで未承諾のXcodeライセンスの確認が必要です。授業前に学校のiPadで試してください。
